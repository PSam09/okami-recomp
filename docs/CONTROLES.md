# Controles e Atalhos de Teclado — Okami Recomp

## Atalhos do Runtime no PC

- **F1**: Abre/fecha o console e depurador visual do runtime.
- **F2**: Ativa/desativa o medidor de FPS na tela (`OKAMI_FPS=1`). Apresenta as chamadas `Flip` por segundo do motor gráfico e a taxa de quadros real da janela.
- **F11**: Alterna entre tela cheia sem bordas e modo janela (`OKAMI_PANTALLA_COMPLETA=0` para iniciar em janela).
- **Esc**: Saída rápida / encerramento do jogo.

## Mapeamento de Controle e Teclado

O runtime nativo suporta gamepads compatíveis com XInput (Xbox), DirectInput e controles PlayStation (DualShock 4 / DualSense) através da camada SDL2.

| Ação no Okami (PS2) | Botão no Controle (Xbox / PS) | Tecla no PC por padrão |
|---|---|---|
| Cruz / A (Pulo / Confirmar) | A / Cruz | Barra de espaço / Enter |
| Círculo / B (Ataque / Ação) | B / Círculo | Z / X |
| Quadrado / X (Pincel Celestial) | X / Quadrado | C / Shift esquerdo |
| Triângulo / Y (Cavar / Menu) | Y / Triângulo | V / Tab |
| L1 / R1 | LB / RB | Q / E |
| L2 / R2 | LT / RT | 1 / 3 |
| Analógico Esquerdo | Analógico Esquerdo | W, A, S, D |
| Analógico Direito (Câmera) | Analógico Direito | Teclas direcionais (Setas) |
