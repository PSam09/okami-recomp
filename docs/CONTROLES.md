# Controles y Atajos de Teclado — Okami Recomp

## Atajos del Runtime en PC

- **F1**: Abre/cierra el depurador y consola del runtime en pantalla.
- **F2**: Activa/desactiva el medidor de FPS en pantalla (`OKAMI_FPS=1`). Muestra los `Flip` por segundo del motor y los refrescos reales de la ventana de Windows.
- **F11**: Alterna entre pantalla completa sin bordes y modo ventana (`OKAMI_PANTALLA_COMPLETA=0` para iniciar en ventana).
- **Esc**: Cierre rapido / salida del juego.

## Mando y Teclado

El runtime se comunica con mandos compatibles con XInput (Xbox), DirectInput y DualShock/DualSense mediante el backend SDL2 del host.

| Accion Okami (PS2) | Boton Mando (Xbox / PS) | Tecla PC por defecto |
|---|---|---|
| Cruz / A (Saltar / Aceptar) | A / Cruz | Barra espaciadora / Enter |
| Circulo / B (Ataque / Accion) | B / Circulo | Z / X |
| Cuadrado / X (Pincel Celestial) | X / Cuadrado | C / Shift izquierdo |
| Triangulo / Y (Cavar / Menu) | Y / Triangulo | V / Tab |
| L1 / R1 | LB / RB | Q / E |
| L2 / R2 | LT / RT | 1 / 3 |
| Stick Izquierdo | Stick Izquierdo | W, A, S, D |
| Stick Derecho (Camara) | Stick Derecho | Flechas de direccion |
